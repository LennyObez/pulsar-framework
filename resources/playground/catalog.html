Pulsar is a PHP 8.5+ HMVC framework designed for regulated, mission-critical domains such as banking, healthcare, and legal. It prioritizes security, compliance, and performance.
Run pulsar new my-project to scaffold a new project. The CLI will guide you through initial setup including database, auth, and module selection.
The current release is 1.0.0-rc.11. The framework is stabilizing toward a GA release with comprehensive test coverage and security reviews.
